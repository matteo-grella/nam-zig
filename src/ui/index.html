Capture your amp

Your amp (or pedal) plays a three-minute test signal, nam-zig records what comes out, then learns a profile from the two. The profile lands in your list, ready to play.

Connect the amp and set the level

Interface output → reamp box (recommended) → amp or pedal input
Amp line out, load box, or microphone → interface input

Never connect a speaker output to the interface: use a load box. Switch off any noise gate, reverb, or delay on the amp, and keep every knob still from now until the recording ends. Unplug the guitar: the interface output plays instead.
